📝 Provision Tenant Baru

ℹ️ Cara dapat Admin Key
  1. Admin Key disimpan sebagai secret di Cloudflare Worker
  2. Lihat / set ulang dengan: wrangler secret put ADMIN_KEY di folder bot
  3. Belum pernah set? Bos bisa set baru dari laptop atau saya bantu bikin lewat Cloudflare dashboard

📋 2 Klien Bos Sekarang

Workflow per klien (5 langkah, ~10 menit):

  1. Generate tenant di form atas → catat tenant_id + api_key
  2. Klien daftar di BerBisnis app (email mereka sendiri)
  3. Bos buka tab Admin di app → cari email klien → tombol "Aktifkan Pro+AI"
  4. Bos copy "📩 Pesan untuk Klien" yang muncul di hasil → kirim via WhatsApp
  5. Klien follow instruksi: setup di Pengaturan + chat /start ke bot Telegram

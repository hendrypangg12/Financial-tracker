Pertanyaan yang Sering Ditanya

Belum yakin? Cek dulu jawaban di bawah, atau langsung WhatsApp.

Apakah saya bisa pakai BerBisnis tanpa AI Bot?

Bisa banget. Paket Starter Rp 149.999/bulan sudah include POS kasir, stok, faktur A4, piutang, PO supplier, dan laporan lengkap — tanpa AI Bot. Upgrade ke Pro+AI hanya kalau bos butuh akses chat dari Telegram.

Bot Telegram-nya tau data saya dari mana?

Setiap kali bos input transaksi di app, data otomatis sync ke cloud kami (terenkripsi, isolated per klien). Bot baca data tsb saat bos tanya. Bot read-only — TIDAK bisa ubah/hapus data.

Aman ga datanya?

Aman. Data tersimpan di Cloudflare + Firebase (tier enterprise). Tiap klien isolated dengan tenant_id + API key sendiri. Tidak ada klien lain bisa lihat data Anda.

Bisa offline ga?

Bisa. App offline-first — bos tetap bisa kasir & input transaksi tanpa internet. Data auto-sync begitu online lagi. Cocok buat toko yang sinyal kadang putus.

Setup ribet ga?

Tidak. Setup ~15 menit. Bos tinggal daftar, isi data toko, import produk (bisa Excel), trial 3 hari. Kalau butuh bantuan, kami onboarding via WA / Zoom.

Bisa cancel kapan aja?

Bisa. Tidak ada kontrak panjang. Bayar bulanan, cancel kapan aja. Data Anda tetap bisa di-export sebagai backup.

Bisa multi-cabang?

Untuk multi-cabang, ambil paket Enterprise. Kami custom setup untuk konsolidasi data semua cabang + akses owner real-time dari pusat.

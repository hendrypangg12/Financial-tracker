📄 Pitch Deck Berstock — Cara Export ke PDF

1. Tekan Cmd+P (Mac) atau Ctrl+P (Windows). Di iPad: tap Share → Print.
2. Pilih "Save as PDF" sebagai destination.
3. Page size: A4 Landscape. Margin: None / Default. Centang "Background graphics".
4. Klik Save — file PDF siap dipakai presentasi atau email.
